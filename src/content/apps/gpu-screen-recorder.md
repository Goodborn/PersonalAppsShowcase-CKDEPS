## Why I chose GPU Screen Recorder

When OBS feels like overkill, this is the closest thing to hitting a record
button that still gives me quality. It encodes straight on the GPU — no CPU
spikes, no dropped frames, no shameful replay buffer lost moments.

## The difference

- Near-zero performance hit while recording games
- Replay buffer so I always have the last N seconds
- Simpler UI than OBS for the "just capture it" cases

## The one tradeoff

It's a simple capture tool — no scenes, no compositing. That's what OBS is for.
These two tools split the job perfectly.
