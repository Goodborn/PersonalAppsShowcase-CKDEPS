## Why I chose Atuin

Every shell ships a history, and it's always the worst UI in the terminal. Atuin
stores history in a real database — so I can search it with fuzzy matching from
anywhere, sync it across machines, and never lose it to a `.bash_history`
rollover again.

## Why I keep using it

- `Ctrl-R` that actually finds the command I need
- Search across all my machines
- Import from my existing bash/zsh/fish history
- No telemetry, fully self-hostable sync

## Why no more plain history

Plain history felt like working without undo. Atuin made that impossible to
go back from.
